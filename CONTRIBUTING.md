# Contributing

Thank you for improving Entgra engineering constitutions.

## Principles

- Keep rules clear, actionable, and verifiable.
- Use normative terms consistently: MUST, MUST NOT, SHOULD, SHOULD NOT, MAY.
- Avoid duplicating universal guidance inside technology-specific modules.
- Keep module IDs stable after release.
- Keep CXF and OSGi changes aligned with the approved middleware guidance.

## Review Checklist

- Module front matter is complete.
- Module IDs match the naming scheme.
- Examples are updated when useful.
- `CHANGELOG.md` is updated for material constitution changes.
