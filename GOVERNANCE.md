# Governance

This repository is maintained as the shared source of truth for Entgra engineering constitutions.

## Maintainer Responsibilities

- Review proposed constitution changes for clarity, applicability, and operational impact.
- Maintain the configuration schema.
- Publish versioned releases for material constitution changes.

## Change Classes

- Editorial clarifications can be reviewed through normal pull requests.
- New optional guidance requires review by the owning engineering area.
- Mandatory requirement changes require explicit maintainer approval and a versioning decision.

## Ownership

Each module declares owners in YAML front matter. Owners are responsible for reviewing changes to that module.
